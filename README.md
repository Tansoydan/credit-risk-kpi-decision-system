# Credit Risk & KPI Decision System

An end-to-end analytics project that transforms raw loan data into
credit approval decisions using SQL-based KPIs, predictive modelling,
and portfolio-level risk simulation.

## Objectives
- Build a production-style analytics workflow using SQL and Python
- Predict probability of default (PD) at loan level
- Translate risk predictions into approval policies
- Evaluate portfolio outcomes under different risk appetites

## Tech Stack
- Python (pandas, scikit-learn)
- SQL (SQLite)
- Power BI / Tableau
